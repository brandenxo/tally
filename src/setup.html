Let's set up your LeetCode repo

About two minutes. We'll fill your repo with a README that updates itself and turn on syncing.

How it works
  1. You solve a problem on LeetCode and click Submit.
  2. On Accepted, this extension saves your code to your GitHub repo.
  3. A README in that repo keeps a running count of everything you've solved.

Your code goes only to GitHub. There's no server and no tracking.

  1. Create an empty repo on GitHub (e.g. leetcode) and tick Add a README. Create repo ↗
  2. Create a fine-grained token for just that repo. Create token ↗
    Repository access: Only select repositories → your repo.
    Permissions: Contents: Read and write and Workflows: Read and write. Expiration: 1 year is fine.
